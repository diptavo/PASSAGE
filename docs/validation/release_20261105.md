# PASSAGE 0.6.1 publication checks

The November 5 publication includes the previously developed 0.6.0 and 0.6.1
interfaces, their tests and calibration evidence, and updated public guides.

- `R CMD check --no-manual` completed with `Status: OK` on R 4.5.1, macOS
  arm64. All 18 test files and package examples passed. The optional `fastICA`
  and `TMB` dependencies were installed in an isolated validation library.
- Both installed interactive examples, `competitive_interactive.R` and
  `robust_interactive.R`, completed successfully using PASSAGE 0.6.1.
- The installed KC2 workflow completed with 199 draws: three pathways and all
  three test routes, nine finite p-values, a versioned configuration and the
  completion marker. This is an execution check, not biological validation.
- The optional TMB compilation/fitting test also passed outside the package
  check. Its short optimization fixture emitted a Hessian/standard-error
  warning (`sqrt(diag(cov))` produced NaNs). This smoke test does not establish
  convergence or usable standard errors for arbitrary joint-factor fits.
- All 23 numerical R-source files match the hashes recorded for the
  [October 31 calibration experiment](calibration_20261031/main/source_hash.csv).
  The large simulations were not rerun for this publication.
- The public site builds successfully, with 85 internal links/assets verified.
  All 22 R/shell code blocks parse, and the published Markdown reference targets
  exist. The displayed website version now comes from `DESCRIPTION`.

The Gaussian rotation assumptions, approximate status of wild refitting and
conditional gene-label interpretation of full-universe competitive tests remain
explicit in the [method guide](../method_choices.md) and
[calibration guide](../robust_calibration.md). Package execution checks do not
replace study-specific calibration or assessment of fitting diagnostics.
