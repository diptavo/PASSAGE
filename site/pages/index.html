What the software provides

PASSAGE returns spot-level component scores, gene loadings, spatial covariance estimates, self-contained and competitive p-values, coverage diagnostics and reproducible analysis records. The bundled example includes 2,166 spots and all 17,630 prepared genes, so both testing questions can be explored.

Research scope. The current Gaussian-reference pathway tests are sensitive to spatially varying noise variance. Successful execution is separate from statistical calibration. Read the assumptions and current limits before interpreting an analysis.

PASSAGE stands for Pathway Assessment of Spatial Signatures via Aggregated Gaussian-process Estimation. This documentation describes version 0.5.0 and its current example workflow.
