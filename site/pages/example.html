Reproduce an analysis

Kidney example

Analyze hypoxia, angiogenesis and inflammatory response in a prepared KC2 kidney cancer sample—with both self-contained and competitive testing.

Methods →Software guide →

What is included

Tissue

2,166 spots

Aligned coordinates, expression, QC and adjustment covariates.

Background

17,630 genes

All prepared genes retained for matched competitive comparisons.

Gene sets

3 pathways

Complete Hallmark lists, with observed and missing genes tracked.

The package contains normalized expression, raw counts, image-pixel coordinates, reference-informed composition estimates and the design matrix. Expression is log1p(10000 × counts / original spot library size). The design has an intercept, standardized library-size and detected-gene measures, and ten composition columns. One fraction is omitted to avoid collinearity.

Genes were retained if detected in at least three spots and nonconstant. This prepared sample has no additional UMI-based spot exclusion. The runner translates coordinates and scales both axes by the longest span. It keeps every prepared spot and gene; it does not restrict the competitive background to the three pathways.

Install once

In a terminal:

git clone https://github.com/diptavo/PASSAGE.git
cd PASSAGE
Rscript -e 'install.packages(c("remotes", "irlba"), repos="https://cloud.r-project.org")'
Rscript -e 'remotes::install_local(".", upgrade="never")'

If you already have the repository, enter its PASSAGE directory, run git pull --ff-only, then rerun the installation command. No separate dataset download is needed.

Run all three pathways

Rscript inst/examples/run_kidney.R

This uses three pathway PCs and 199 null draws. It writes results/kidney_all/ and performs:

  1. Covariate-adjusted PCA separately within each pathway, saving scores and loadings.
  2. The self-contained GP covariance comparison, sharing a 64-feature kernel cache across pathways.
  3. Fixed-kernel trace and largest-root tests, combined into a corrected omnibus result as a sensitivity analysis.
  4. Global PCA across all 17,630 genes, followed by competitive testing against matched sets that exclude each target pathway.

For better Monte Carlo resolution, use 9,999 draws and a new output directory:

Rscript inst/examples/run_kidney.R all 9999 results/kidney_9999

199 is an execution check with a raw p-value floor of 0.005; 9999 lowers that floor to 0.0001. Choose draws for the intended testing threshold. Increasing draws does not address model misspecification.

Choose a route or estimator

Run only the route you need:

Rscript inst/examples/run_kidney.R competitive 9999 results/kidney_competitive
Rscript inst/examples/run_kidney.R gp 9999 results/kidney_gp
Rscript inst/examples/run_kidney.R fixed 9999 results/kidney_fixed

The final optional arguments select the pathway estimator and rank:

# Three pathway factors
Rscript inst/examples/run_kidney.R gp 199 results/kidney_fa factor_analysis 3

# Enough pathway PCs to retain 95% of adjusted variance
Rscript inst/examples/run_kidney.R gp 199 results/kidney_pca95 pca auto

Run from R

After installing PASSAGE and irlba, the installed package also provides the same runner. A repository checkout is unnecessary:

library(PASSAGE)
source(system.file("examples", "run_kidney.R", package = "PASSAGE"))
run_kidney()

# Check a prespecified alternative kernel approximation
run_kidney(mode = "gp", B = 199, n_features = 128,
           output = "results/kidney_gp128")

To inspect the bundle or use the individual R functions:

b <- passage_validate_bundle(
  system.file("extdata", "kidney_KC2.rds", package = "PASSAGE")
)
dim(b$Y)
names(b$pathway_sets)
colnames(b$X)
Add descriptive GpGp fits 
install.packages(c("GpGp", "fields"))
run_kidney(mode = "gp", B = 199, descriptive_gp = TRUE,
           output = "results/kidney_descriptive")

Inspect convergence flags for these optional component fits. They are separate from the GP test and do not supply its p-value.

Read the results

results <- read.csv("results/kidney_all/summary.csv")
results[, c("pathway", "test", "p", "q_BH_within_test")]

summary.csv has nine rows for an all run: three pathways × three test routes. It records raw p-values, BH/BY adjustments across pathways within each route, and BH/BY adjustments across all nine reported hypotheses.

The GP comparison is the example’s primary self-contained test. The fixed-kernel result is a sensitivity analysis, and the competitive result answers a separate background-relative question. Read the output interpretation before comparing them.

This is a runnable analysis, not a biological validation. Composition covariates were estimated from the same counts and are treated as fixed. Current Gaussian-reference tests are sensitive to spatially varying noise variance. Review QC, matching, calibration and replication before claiming pathway activity specific to a disease or cell population.

Data provenance and scope

The source kidney data are from Dawo, Nonchev and Silina’s Zenodo deposit (2025, version 1), DOI 10.5281/zenodo.14620362, under CC BY 4.0. The Human MSigDB Hallmark lists retain their source license terms. The gene-set snapshot was prepared on October 22, 2026; its exact MSigDB release number was not recorded.

The provenance record documents preprocessing, the composition reference, attribution, licenses and the bundled file checksum. Histology images and annotations are not included. GWAS integration requires separate genetic data and an LD-aware downstream method.
