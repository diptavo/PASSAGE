Understand PASSAGE

Methods

A pathway is a collection of genes. PASSAGE summarizes their shared activity, then asks what its pattern across tissue tells us.

Software guide →Example analysis →

Two scientific questions

Self-contained

Does this pathway have spatial structure?

After accounting for the chosen covariates, do nearby spots have related pathway activity? The reference is a pathway with no remaining cross-spot spatial dependence under the working model.

Competitive

Is it more spatial than comparable genes?

Does the pathway’s spatial score exceed those of matched gene sets drawn from the measured background? The reference is other genes, rather than an absence of all spatial structure.

A pathway can pass the self-contained test without passing the competitive test. For example, it may follow a broad tissue pattern that many other genes also follow. Passing both provides evidence of spatial organization and enrichment relative to the chosen background; it does not establish a causal mechanism.

How estimation feeds testing

01 / ADJUSTExpression within a pathwayRemove variation explained by the specified covariates.
02 / ESTIMATEActivity componentsUse PCA or factor analysis to obtain spot scores and gene loadings.
03 / TESTSpatial organizationTest the estimated, unsmoothed scores using tissue coordinates.

Estimation contributes the representation that is tested. Instead of treating every pathway gene as a separate outcome, PASSAGE extracts a few joint patterns. Each component assigns a score to every spot; its loadings describe the genes contributing to that pattern. A spatial test then examines these estimated scores.

In the GP comparison, estimation also occurs inside the test: PASSAGE fits a spatial range and a spatial variance fraction for each component. How much those fitted models improve on nonspatial models determines the test statistic. The null simulations repeat that parameter search.

The competitive workflow has its own estimation step. It fits a global PCA model across the full gene background, then uses the fitted loadings, residual variances and spatial kernels to score target and matched gene sets. It does not reuse the pathway-only fits.

Choose an activity representation

OptionIntuitionChoice to make

Pathway PCA and factor analysis use expression and covariates, without coordinates. Their scores remain unsmoothed for testing. Smoothing would impose spatial similarity even on noise and would need a different null calibration.

Rank changes the biological signal that can be detected. A small rank is compact but can discard a weak spatial pattern. A variance threshold retains more variation but may include additional noise. Choose the rule before inspecting p-values. Every pathway test concerns the retained components, not every possible pattern in the pathway.

Choose an inference route

1. GP covariance comparison

Intuition: compare two explanations of the component scores: independent spot noise, or noise plus a spatially correlated signal. A Gaussian process (GP) describes how strongly activity is related at different distances.

The test searches a prespecified grid of spatial ranges and variance fractions for each component. It adds the improvements in fit across components. With correlated factor-analysis scores this is a composite statistic, rather than a joint independent-factor likelihood ratio.

How the reference is made: jointly rotate the estimated scores in the covariate-residual space, preserving their cross-component relationships but randomizing their orientation relative to the tissue. Repeat the same GP fitting on each draw. The p-value measures how often a null statistic is at least as large as the observed one; it is not taken from a standard chi-square table.

Under the stated Gaussian null, these rotations preserve the gene cross-products used by pathway PCA and the implemented factor analysis. The estimator’s loadings and rank rule can be conditioned on, so repeatedly refitting PCA or FA is unnecessary. Repeating the GP parameter search remains necessary because spatial fit changes with the rotation.

Use: the primary self-contained route in the example. The low-rank kernel approximation makes larger datasets practical while retaining all spots. The dense option is a reference for smaller datasets. These are computational choices for the same testing question; feature count can still change approximation accuracy and power.

2. Fixed-kernel subspace tests

Intuition: choose a spatial similarity pattern in advance and ask how closely the estimated pathway span aligns with it. The trace statistic collects alignment across directions; the largest root emphasizes the strongest direction.

How the reference is made: compare the observed alignment with random Gaussian subspaces after covariate adjustment. The optional omnibus p-value corrects for trying both statistics within the pathway. It does not correct for multiple pathways.

Use: a prespecified spatial-scale analysis or a sensitivity analysis alongside the GP test. A range learned from the same scores cannot simply be plugged into this fixed-kernel reference. The implemented largest-root test uses simulated calibration, not an ordinary Tracy–Widom approximation. These APIs also do not implement PC-wise SKAT with Davies calibration or Fisher/ACAT combinations.

3. Competitive matched-set testing

Intuition: compare the pathway with other gene sets that had a similar opportunity to show signal. The standard workflow fits global PCA followed by spatial modeling with a Vecchia approximation, which represents GP dependence through local neighbor relationships.

Default comparison sets match expression level, detection frequency and variance. Each set contains unique genes and excludes the target pathway’s genes. The procedure preserves matching-stratum counts and stops if the background cannot support the match. Optional module matching can add another constraint.

How the reference is made: compute the same score for many matched sets and count how often they reach or exceed the target score. The field score_z is a statistic name; its p-value comes from this empirical comparison, not a standard-normal tail.

These workflows are complementary. The current competitive API uses a global fit. A competitive version of the pathway-only GP test would need to fit PCA or FA and the GP comparison again for every matched set. That route is not currently implemented.

Monte Carlo resolution depends on the number of null draws, B. The smallest raw p-value is 1 / (B + 1): 0.005 for 199 draws and 0.0001 for 9,999. The fixed-test omnibus has twice that floor because it corrects over two statistics. More draws improve tail resolution; they do not repair a misspecified null model.

Adjustment and current limits

Covariates define the question. Adjusting for technical measurements asks about signal beyond those measurements. Adjusting for cell composition asks about signal beyond the estimated cell mixture, which can remove biology you intended to study. Estimates derived from the same expression are treated as fixed here; their uncertainty is not propagated.

Spatially varying noise remains a limitation. The pathway references assume independent Gaussian spot errors with a common gene covariance after adjustment. They allow genes to be correlated, but do not allow arbitrary location-dependent noise variance. A variance gradient can appear significant even without correlation between spots.

In a 200-replicate pilot, GP rejection rates under Gaussian nulls were 2.0–4.5% at a nominal 5%. Under a strong heteroskedastic null stress, they rose to 14.5–25.0%; fixed-kernel tests also inflated. A calibrated heteroskedasticity correction is not implemented.

Competitive testing has a different assumption: target and comparison genes must be exchangeable within the matching strata. Matching a few summaries helps define a relevant comparison but does not establish this assumption for every dataset.

Before interpreting findings, examine QC and gene coverage, check approximation sensitivity using prespecified settings, define the family of pathways and samples, and seek replication. See the detailed pilot and mathematical specification for the scope of current validation.

Other fitting engines

The R package also provides research options for estimating spatial factors. A fitting engine estimates a representation; it does not automatically supply a calibrated pathway test.

Intuition behind the advanced options
EngineIntuition and role
spatial_basisDescribe expression using smooth spatial basis functions, then compress the fitted surface into factors.
smoothed_pcaStart with PCA, smooth the component scores over space and refit gene loadings.

These are lower-level options, not interchangeable arguments to the kidney example. Coordinate-informed or smoothed scores cannot replace unsmoothed PCA/FA scores in the current pathway rotation tests without new calibration. TMB model-comparison outputs are not a calibrated test of zero spatial variance at the boundary.

The separate GpGp function fits descriptive covariance models and reports convergence. It does not provide pathway-test p-values or feed its estimates into the main tests. The GP comparison already estimates its own spatial parameters internally.

Where GWAS fits

Spatial analysis can prioritize pathways and genes for a genetic follow-up. GWAS integration is a separate downstream analysis requiring GWAS statistics, a defined variant-to-gene mapping strategy, and an association or enrichment method that accounts for linkage disequilibrium. A spatial PASSAGE result alone is not evidence of a genetic association.
